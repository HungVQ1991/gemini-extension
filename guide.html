Gemini Power Suite

Quick User Guide & Keyboard Shortcuts

1. Prompt Library & Chains

Quick Insert Commands

  • Type // in the Gemini composer to open the Prompt Library search popup.
  • Type ,, in the Gemini composer to insert a Prompt Chain.
  • Use variables like {{variable_name}} in prompts for interactive replacement prompts before sending.

2. Folders & Organization

Organize Chats

  • Create custom folders with colors in the Gemini sidebar.
  • Drag and drop chats into folders, or use the chat context menu.
  • Bookmark important response turns within conversations for quick access.

3. Prompt Optimization & Grammar Fix

Enhance Your Queries

  • Click the Optimize button next to the composer to rewrite and upgrade your prompt.
  • Press Ctrl+Shift+G (or your custom shortcut) to automatically correct spelling and grammar errors.

4. Message Queue

Continuous Sending

  • While Gemini is generating a response, press Enter to add your message to the sequential queue.
  • Messages in the queue are sent automatically as soon as Gemini finishes generating the previous response.

5. Export & Utilities

Chat Tools

  • Export conversations to Markdown, PDF, or DOCX via the export button.
  • Upload entire folders as bundled context by clicking the folder button next to the file uploader.
  • Use the double-click action on the scroll-down button to toggle auto-scroll during response generation.
